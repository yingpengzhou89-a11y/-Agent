# 固定回答评测集（Phase 2）

本项目将评分验证拆成两部分：

1. `backend/tests/test_evaluation_benchmark.py` 使用固定回答，保护确定性检查（非空、长度、预期关键点命中、项目证据）和后端 Rubric 聚合不发生漂移；
2. 模型定性评分由可注入的 `ModelGateway` 提供。接入或更换模型时，应使用同一套固定题目、候选人资料与 Prompt 版本离线运行，并比较维度分数和置信度分布。

当前基准样例覆盖 RAG 流程题的空回答、仅覆盖关键点回答和结构化完整回答。新增题型时，需要同时增加：题目、预期关键点、项目资料边界、记录的模型输出以及预期总分。

这套测试不宣称不同大模型的语义评分天然一致；它保证模型输出进入系统后，确定性检查、权重聚合和持久化格式始终一致、可复现。
